# MURUJ — موقع مروج (JMG Real Estate)

```
MURUJ/
├── README.md
├── backend/                ← يتلصق في Google Apps Script
│   ├── Config.gs           ← الإعدادات ومفاتيح الـ API
│   └── Code.gs             ← منطق الباك إند
└── frontend/               ← يترفع على GitHub Pages
    ├── index.html (الدخول)  home  devs  dev  links  mail  clients  dash  staff  settings  brand  tools
    ├── view.html           ← صفحة العميل (الرابط المؤقت)
    ├── config.js           ← رابط الباك إند (عدّله)
    ├── sw.js  manifest.json
    ├── css/  js/  assets/
```

## التشغيل
1. **الباك إند:** Google Sheet جديد ← Extensions ← Apps Script ← ملفين `Config` و`Code` (Config فوق Code) ← شغّل `setup` مرة واحدة ووافق على الصلاحيات ← Deploy كـ Web app (Execute as: Me / Access: Anyone) وانسخ الرابط.
2. **الواجهة:** حط الرابط في `frontend/config.js`، وبدّل `USERNAME` و`REPO` في سطر `og:image` في ملفات `.html` برابط موقعك، وارفع **محتويات** مجلد `frontend` على GitHub (بحيث `index.html` في الجذر) وفعّل Pages.
3. **أول دخول:** `JMG` وباسورد `123456789`، وغيّره من الإعدادات فوراً.

## لو بتحدّث نسخة قديمة
شغّل `setup` تاني (بيضيف الأعمدة الجديدة ومبيمسحش بياناتك) وبعدين Deploy ← Manage deployments ← **New version**. وارفع كل ملفات `frontend` من جديد. الروابط المؤقتة القديمة لسه شغالة.

## روابط نظيفة (من غير .html)
الموقع بيستخدم `/devs` و`/view?v=...` بدل `/devs.html`. GitHub Pages بيخدم الاتنين، بس ملفات الـ`.html` لازم تفضل بأسمائها على GitHub. على استضافة تانية لازم تفعّل الروابط من غير امتداد.

## المميزات
- **الرئيسية:** تعريف المشروع (صور + ماستر بلان 3D + فيديو + نص) من "تعديل الرئيسية"، وزرار **مشاركة** برابط مؤقت.
- **صفحة المطور:** التفاصيل أول حاجة (10 سطور + "عرض المزيد")، ثم المجسمات 3D، والصور بسلايدر تلقائي، والفيديوهات. شريط تنسيق النص ثابت أثناء التعديل.
- **المجسمات:** ماستر بلان / مبنى / وحدة، لكل نوع بياناته وحالته.
- **عملاء جدد:** شيت بالعملاء المسجلين من الرابط الجديد. الموظف يشوف عملاءه بس، والأدمن يشوف الكل بفلتر بالموظف، والكل ينزّل Excel.
- **البريد:** محادثات + طلبات التحديث بحالات (جديد / جاري / تم). **الأدوات:** استخراج صور PDF بدون علامة مائية.
- **العلامة المائية:** حجم ووضوح من "الهوية"، ومبتظهرش للأدمن. **الصلاحيات:** تتغير فوراً من غير ما الموظف يعمل خروج ودخول.

## الأمان والثبات (اتراجع في آخر إصدار)
- الباك إند بيرفض أي ملف مش جوه مجلد المشروع (منع الوصول لملفات تانية في Drive أو نشرها أو حذفها).
- صور الشعار والأفاتار لازم تكون صور حقيقية، وكل النصوص بتتعرض بشكل آمن (اتجرب بمحاولات حقن على كل الصفحات).
- عمليات التعديل بتتنفذ بالدور (قفل) عشان البيانات ماتتلخبطش لو اتنين عدّلوا مع بعض.
- 5 محاولات دخول غلط تقفل الحساب 15 دقيقة.

## واتساب
حط `WA_TOKEN` و`WA_PHONE_ID` والقالب في `backend/Config.gs`. الملف ده يتلصق في Apps Script بس، ماترفعوش على GitHub.

## ملاحظات
- صيغ الـ3D: GLB وGLTF (ملف واحد) وOBJ وFBX وSTL وPLY وDAE و3DS. الأفضل GLB.
- أداة الـPDF لا تدعم الملفات المشفرة أو صيغ نادرة (JPEG2000/CMYK).
- منع السكرين شوت مستحيل تقنياً على الويب. الحماية بالعلامة المائية ومنع الحفظ والنسخ وتغبيش الصفحة عند الخروج.

## تحديث: الترجمة التلقائية + محرر النصوص
- **الترجمة:** لما اللغة تتغير لإنجليزي، اسم المشروع والمطورين والتفاصيل وعناوين الوحدات بتتترجم لوحدها (الباك إند بيستخدم LanguageApp المجاني ويحفظ الترجمة في شيت `Trans`). لازم: شغّل `setup` مرة، وبعدين Deploy ← Manage deployments ← **New version**.
- لو عايز اسم معين يتكتب بشكل محدد بالإنجليزي، ضيفه في `GL` في بداية قسم الترجمة في `js/core.js` (مثال: `'مروج':'Muruj'`).
- **المحرر:** نوع الخط والحجم واللون والتظليل والمحاذاة والقوائم، واللصق بيتنضف تلقائياً. تفاصيل الوحدة بقت بنفس المحرر.
- **ما تستبدلش `config.js`** عندك، فيه رابط الباك إند بتاعك.

## الرفع في الخلفية
- زرار **حفظ** بيقفل النافذة فوراً، والرفع بيكمل في كروت جنب الشاشة (نسبة مئوية، وكل عملية كارت تحت التانية).
- الصور بتترفع 3 مع بعض، والفيديو/المجسم على أجزاء 8MB. الكارت بيختفي لوحده بعد النجاح، ولو فشل بيظهر زرار **إعادة المحاولة** من غير ما يعيد اللي اترفع.
- ممكن تكمل تتصفح في نفس الصفحة، لكن لو غيرت الصفحة والرفع شغال هتظهرلك رسالة تأكيد لأن الرفع هيتلغي.
- بعد تحديث الواجهة لازم تحدّث `Code.gs` وتعمل **New version** (فيه أكشن `upImg` الجديد).
