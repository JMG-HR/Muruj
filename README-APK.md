# بناء تطبيق أندرويد (APK) من GitHub

التطبيق بيفتح موقعك الحي **وكل صفحاته جوه التطبيق**، وأي تعديل في الموقع أو الباك إند أو الهوية بيظهر فيه فوراً.

## رابط الموقع بيتسحب تلقائي
الـWorkflow بيحدد الرابط لوحده وقت البناء:
1. من إعدادات **GitHub Pages** للريبو (يشمل الدومين المخصص لو عندك).
2. وإلا من اسم المستخدم والريبو: `https://USER.github.io/REPO/` (وللريبو اللي اسمه `USER.github.io` بيبقى `https://USER.github.io/`).
3. أو تكتبه بإيدك من **Run workflow ← site_url**.

يعني لو نقلت المشروع لريبو تاني أو شركة تانية، الـAPK الجديد بيتبني على رابط الريبو ده من غير أي تعديل. اسم التطبيق بيتحدد من **Run workflow ← app_name** (وبدون apostrophe `'`).

## الخطوات
1. ارفع محتوى المجلد `1-GITHUB-REPO` في جذر الريبو (فيه الموقع و`android/` و`.github/`).
   **ما تستبدلش `config.js` بتاعك** (الملف `config.example.js` مجرد مثال).
2. تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
3. بعد 3-6 دقايق نزّل **MURUJ-apk** من Artifacts وهتلاقي `app-debug.apk`، انقله للموبايل وثبّته.
4. بعد كده أي تعديل في `android/` بيبني APK جديد تلقائياً.

البناء بـ **Java 21 (Temurin)** و Gradle 8.9 و Android SDK 35، ومستوى لغة الكود 17 لأنه أعلى مستوى بيدعمه أندرويد حالياً.

## إعدادات تانية
- `android/app/build.gradle`: `applicationId` (لازم فريد لكل تطبيق).
- الأيقونات: `android/app/src/main/res/mipmap-*/ic_launcher*.png`.

## ملاحظات
- النسخة «debug»: بتتثبت على أي موبايل، لكنها مش للنشر على Google Play (ده محتاج نسخة release موقّعة بمفتاحك).
- مفيش إشعارات Push.
